# RBAS — Roblox Game AI Studio

An AI game studio for Roblox on your desktop. You talk to the **Lead**; it plans with you and hands the work to a team of specialist agents (Scripter, World Builder, UI Designer, 3D Artist, VFX, Sound, Animator, Economy, Researcher, Thumbnail Maker, Playtester, Code Reviewer) who build straight into Roblox Studio.

- Use any model from any provider: your Claude or ChatGPT subscription, API keys, OpenRouter (including free models), fal.ai, or local models through Ollama.
- A per-game vault (Obsidian-compatible) remembers what the AI knows about your game.
- Free thumbnails and icons with Recraft V4.1 Flash V2 on OpenRouter.

## Download

**[Get the latest installer →](https://github.com/Radin-dev1/rbas-releases/releases/latest)** (`RBAS-Setup-<version>.exe`, Windows 10/11, 64-bit)

Windows may warn that the installer is from an unknown publisher because it is not code-signed yet. Click **More info → Run anyway**.

## Updates

RBAS checks for updates when it starts and every few hours. When a new version is out, a popup offers **Update**: it downloads, installs and restarts. Your games, chats, vaults and keys are kept. You can also check from **Settings → About and updates**.

## Getting started

1. Install and open RBAS.
2. **Settings → AI providers**: log in to Claude Code or Codex once in a terminal, or paste an API key.
3. **Settings → Roblox Studio → Install Studio plugin**, restart Studio, then click **RBAS → Connect** in the Plugins tab.
4. Tell the Lead what you want to build.
